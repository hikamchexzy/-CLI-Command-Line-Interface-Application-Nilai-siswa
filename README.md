# -CLI-Command-Line-Interface-Application-Nilai-siswa
Aplikasi CLI Manajemen Nilai Siswa adalah program berbasis command-line interface (CLI) yang dibangun dengan Python Fundamental. Program ini memungkinkan pengguna untuk mengelola data nilai mata pelajaran siswa secara sederhana dan efisien. Data disimpan dalam list of lists dan dapat diakses melalui menu interaktif.
# Aplikasi Nilai Siswa (CLI)

Program CLI sederhana untuk mengelola data nilai mata pelajaran siswa.

## Fitur
- Tambah data (mapel & nilai, dengan validasi)
- Hapus data
- Tampilkan data dalam bentuk tabel
- Hitung rata-rata nilai
- Urutkan data (nilai besar-kecil, kecil-besar, atau nama mapel A-Z/Z-A)

## Cara Menjalankan
```bash
python main.py
